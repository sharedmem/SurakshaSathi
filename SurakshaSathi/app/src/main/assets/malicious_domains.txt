# Malicious domain blocklist — SMS Sideloading Spam Detector
# ============================================================
# One domain per line (lowercase, no scheme/path). Lines starting with '#'
# are comments and blank lines are ignored (loader in url_intelligence.py
# does a plain substring/set lookup, so keep entries as bare registrable
# domains, e.g. "sbi-secure-update.in" not "https://sbi-secure-update.in/x").
#
# These are synthetic/illustrative fraud domains matching the patterns used
# in this project's synthetic training & evaluation datasets (fake banking
# KYC portals, fake govt e-challan sites, fake courier/delivery trackers,
# fake loan apps, fake OTT/telecom renewal pages) plus common shortener
# -abuse and brand-impersonation patterns seen in real Indian smishing
# campaigns. None of these are live/active malware infrastructure — this
# is a defensive heuristic seed list, meant to be extended with real
# threat-intel feeds (e.g. PhishTank, OpenPhish, CERT-In advisories) in
# production.
